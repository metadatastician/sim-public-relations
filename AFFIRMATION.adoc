= PR Practice Lab — Affirmation Status
:toc: left

== Status

No formal release affirmation has been issued for PR Practice Lab. This file is
an honest capability snapshot for the Phase A publication candidate, not a
signed release certificate and not a claim of product readiness.

== What is presently checkable

The repository contains a deterministic Zig replay kernel, four implemented
golden routes, a Northstar Mobility authored scenario, a provisional assessment
model and a source-side hidden-reality boundary validator with planted-failure
canaries.

The commands that must ground any current capability statement are:

[source,sh]
----
zig build test
zig build run -- golden
bash tools/validate-scenario.sh
bash tools/test-scenario-boundary.sh
----

Their horizon is limited to the native kernel, declared golden replay,
source-side scenario structure and the three planted boundary defects. A pass
does not establish the complete learner product, professional validity,
accessibility conformance, deployment readiness or hidden-truth isolation over
packaged/runtime channels.

== What is not affirmed

This repository does not presently affirm that:

* an interactive learner interface, persistence layer, facilitator view or
  evidence-passport export exists;
* hidden authored reality is excluded from every future package, binary,
  runtime, prompt or side channel;
* the scenario, competency framework or rubric has been reviewed or validated
  by practitioners, professional bodies, employers, educators, accessibility
  specialists or early-career learners;
* the software is a qualification, accredited CPD, employment, a placement,
  live client work or evidence of suitability for a particular job; or
* the inherited RSR repository scaffold has been fully converted or removed.

Known gaps are maintained in `docs/KNOWN-DEBT.adoc`. A future formal affirmation
must name an exact signed commit, UTC timestamp, toolchain and complete live
check output. Until then, this document must not be presented as such an
affirmation.
