= PR Practice Lab Audit Gate
:toc: left

== Purpose

This is the repository-local audit posture for PR Practice Lab. It prevents
product, assessment and release claims from outrunning executable evidence or
external professional review.

== Hard rules

* Never represent simulated work or elapsed simulation time as employment,
  placement hours, live client work, a qualification or accredited CPD.
* Never deliver hidden authored reality, response rules, assessment
  interpretations or model routes to a learner client or learner-controlled AI.
* Never infer competence from campaign outcome, prose fluency, accent, social
  background, personal following or tool access alone.
* Never describe provisional and unreviewed professional material as
  authoritative scoring.
* Never call the learner product complete while the interface, persistence,
  facilitator workflow and evidence-passport export do not exist.
* Never treat a negative leak scan as evidence until planted positive defects
  have shown that the instrument can fail.
* Never weaken or bypass a failing gate to obtain a green result.
* Documentation and publication claims must state the horizon of the check that
  supports them.

== Phase A evidence

The publication candidate must pass:

[source,sh]
----
zig build test
zig build run -- golden
bash tools/validate-scenario.sh
bash tools/test-scenario-boundary.sh
----

These checks cover the current native replay kernel, deterministic golden
routes, source-side scenario alignment and planted boundary failures. They do
not establish accessibility, practitioner validation, deployment readiness or
runtime/package isolation.

== Release blockers

The known blockers and gaps are recorded in `docs/KNOWN-DEBT.adoc`. In
particular, no authoritative assessment or professional-validity claim may be
made before competent external review, calibration and pilot evidence exist.

Canonical estate-wide repository and publication standards remain in the
`hyperpolymath/standards` repository. This file adds the product-specific audit
boundary; it does not replace that canon.
