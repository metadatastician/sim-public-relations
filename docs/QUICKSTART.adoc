= Quickstart
:toc: preamble

PR Practice Lab currently has a native deterministic replay and assessment
slice, but not yet an interactive learner application.

Validate the first scenario and prove the boundary test can fail:

[source,bash]
----
zig build test
zig build run -- home
zig build run -- golden
bash tools/validate-scenario.sh
bash tools/test-scenario-boundary.sh
----
